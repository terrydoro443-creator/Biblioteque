## Astro Défense 🚀

Un mini jeu d'arcade jouable directement dans le navigateur, sans aucune installation ni dépendance.

### Comment jouer

Ouvre simplement le fichier `index.html` dans ton navigateur (double-clic, ou glisser-déposer dans une fenêtre de navigateur).

- **⬅️ / ➡️** ou **A / D** : déplacer le vaisseau
- **Espace** ou **⬆️** : tirer
- Sur mobile/tablette : boutons tactiles affichés en bas de l'écran

### Objectif

Détruis les vagues d'envahisseurs avant qu'ils n'atteignent le bas de l'écran. Chaque vague terminée augmente la difficulté (plus d'ennemis, plus rapides). Tu as 3 vies. Le meilleur score est sauvegardé automatiquement dans le navigateur.

Tout est contenu dans un seul fichier HTML (HTML/CSS/JS + sons synthétisés), donc le jeu fonctionne aussi bien en local que hébergé sur n'importe quel serveur statique (GitHub Pages, Netlify, etc.).

## Lumen Dash 🌌 (3D)

Un jeu de course/dodge en 3D (Three.js) avec un personnage animé, dans un canyon néon.

### Comment jouer

Ouvre `lumen-dash/index.html` dans ton navigateur (le fichier `lumen-dash/three.min.js` doit rester à côté).

- **⇆** (flèches/A-D) : changer de voie
- **⇧** (flèche haut/Espace) : sauter par-dessus les obstacles bas
- **⇩** (flèche bas) : glisser sous les barres
- Sur téléphone : glisse le doigt sur l'écran, ou utilise les boutons en bas
- Choisis ton personnage sur l'écran d'accueil, récolte les orbes dorées et les orbes bleues (bouclier temporaire)

Meilleur score et skin choisi sont sauvegardés automatiquement dans le navigateur.

Une version en ligne, jouable sans rien installer, est aussi disponible ici : https://claude.ai/artifact/XkmXf3nwnZbcGJd7QwUSiT

## Rupture Titan ⚔️ (3D, combat de boss)

Un jeu de combat 3D en arène : affronte 3 boss d'affilée, chacun avec ses propres attaques télégraphiées à esquiver.

### Comment jouer

Ouvre `rupture-titan/index.html` dans ton navigateur (le fichier `rupture-titan/three.min.js` doit rester à côté).

- Déplacement : flèches/ZQSD, ou joystick tactile à gauche sur mobile
- **Espace** ou bouton ⚔ : frapper (le personnage fait toujours face au boss automatiquement)
- **Maj** ou bouton ⤺ : esquiver (brève invincibilité)
- Les boss s'illuminent juste avant d'attaquer (attaque au corps-à-corps, onde de choc au sol, ou charge) — déplace-toi ou esquive pendant ce court laps de temps
- Choisis ton personnage sur l'écran d'accueil ; vaincs les 3 boss pour gagner

Une version en ligne, jouable sans rien installer, est disponible ici : https://claude.ai/artifact/G1mjZsFCkDWh3jT4Ls76Ts

## Zone Rouge 🎯 (3D, FPS à la Call of Duty)

Un jeu de tir à la première personne en 3D : vise avec la souris/le doigt, tire sur les bots hostiles, recharge, survis le plus longtemps possible dans l'arène.

### Comment jouer

Ouvre `zone-rouge/index.html` dans ton navigateur (le fichier `zone-rouge/three.min.js` doit rester à côté).

- **ZQSD** : se déplacer, **souris** : viser, **clic gauche** : tirer, **R** : recharger
- Sur téléphone : joystick à gauche pour bouger, glisse n'importe où à droite pour viser (vraie vue à la première personne), bouton pour tirer
- Les bots réapparaissent en continu — enchaîne les éliminations et tiens le plus longtemps possible avant de tomber

Une version en ligne, jouable sans rien installer, est disponible ici : https://claude.ai/artifact/75AaNENp31Kt8gM2TyeSU2
